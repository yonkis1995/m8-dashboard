# Правила работы с репозиторием

Для сообщений коммитов используется формат Conventional Commits:

```text
<type>: <краткое описание>
```

Основные типы: `feat:`, `fix:`, `refactor:`, `docs:`, `style:`, `ci:`, `chore:`, `perf:`, `test:`.

Сообщение должно кратко описывать одно логическое изменение. Не следует объединять несвязанные изменения в один коммит.
