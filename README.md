# М-8 «Холмогоры»

Интерактивный дашборд по планируемым мероприятиям на М-8 и оценке изменения времени в пути.

## Функционал

Ресурс позволяет:

- просматривать на интерактивной карте планируемые мероприятия по строительству и реконструкции участков М-8 «Холмогоры»;
- получать информацию по каждому мероприятию: статус, сроки реализации, протяженность, параметры существующего и перспективного состояния;
- выбирать корреспонденцию между населенными пунктами и просматривать оценку изменения времени в пути на автомобиле;
- просматривать расчетный диапазон времени и экономии по годам с учетом условий движения и сроков реализации мероприятий.

В качестве существующего времени в пути для корреспонденций с Москвой принято среднее время поездки при прибытии в Москву в утренний час-пик. Точка прибытия в Москве — ТТК.

Диапазон формируется только за счет моделируемых участков: до реконструкции используются заданные скорости для неблагоприятных и нормальных условий; после реконструкции — 80–95 км/ч, а для платного дублера км 115–135 — 95–110 км/ч. Для прочей части маршрута время одинаково в обеих ветках.
